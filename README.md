# TXagency — marketing site (Vite + React + Tailwind)

Vite + React + TypeScript + Tailwind. Import this repo into Lovable, or run locally.

## Local
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Routes: `/` (home), `/artiklar` (articles), `/artiklar/:slug` (article).
All contact CTAs open the booking drawer; the drawer composes a WhatsApp
message on submit (no backend).
